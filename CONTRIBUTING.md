# Contributing

Thanks for contributing to `awesome-nanobanana-prompts`.

## What to Contribute

- High-quality prompts for Nano Banana / Nano Banana Pro
- Clear input-output examples (prompt + image)
- Prompt templates that are reusable and practical
- Category cleanup, typo fixes, and translation fixes

## Submission Rules

1. Keep prompts readable and runnable.
2. Add the prompt to the most relevant category.
3. Use concise titles in English (and Chinese when helpful).
4. Prefer real examples with image references under `images/`.
5. Do not submit copyrighted or private material without permission.

## Suggested Entry Format

````md
**Example: <Short Title>**

<img width="600" alt="Image" src="./images/<path>.png" />

<details>
<summary>Prompt (Click to expand)</summary>

```text
<your prompt>
```

</details>

<hr />
````

## Pull Request Checklist

- [ ] Title is clear and scoped
- [ ] Added/updated content is in the right section
- [ ] Markdown renders correctly on GitHub
- [ ] Image paths are valid
- [ ] No accidental language mix-ups in English-only sections
- [ ] No standalone `---` separators (use `<hr />`)

## Commit Message Recommendation

- `docs: add <category> prompt examples`
- `docs: fix readme translation and formatting`
- `docs: normalize separators and example numbering`

# 贡献指南（中文）

感谢你为 `awesome-nanobanana-prompts` 做贡献。

## 可贡献内容

- 高质量 Nano Banana / Nano Banana Pro 提示词
- 清晰的输入输出示例（提示词 + 图片）
- 可复用模板
- 分类整理、错别字修复、中英文对齐优化

## 提交规范

1. 提示词需可读、可复用。
2. 放到最匹配的分类。
3. 标题尽量简洁明确。
4. 优先提供图片示例，并放在 `images/`。
5. 不要提交未授权的版权素材或隐私内容。

## PR 自检

- [ ] 分类正确
- [ ] Markdown 在 GitHub 渲染正常
- [ ] 图片路径有效
- [ ] 英文区块无误混入中文
- [ ] 分隔线统一使用 `<hr />`
